  production                （in-sample の記録なし）

【選ばれたハイパーパラメータ】窓内の時系列CVのみで決定

  production / quantile
    alpha           0.1 が 5500回  ← グリッドが選んでいません

  production / quantile_wide
    alpha           1.0 が 4507回、0.1 が 993回

  production / tree
    max_depth       2 が 4452回、3 が 657回、4 が 391回

  分割は TimeSeriesSplit のみです。Random K-Fold はこのリポジトリのどこでも使っていません。
