### 6-2b. その「良くなった」は、減らした以上のことをしているか

往復0.200%を払う以上、建玉を減らすだけで累積は改善します。
だから「全部買うより良い」は、ルールについて何も言っていません。
正しい対照は、**同じ建玉数を、技術なしで選んだ場合**です。
各ルールの回帰条件を満たす集合から無作為に同数を選び、2,000回試した分布と比べます。

| ルール | 建玉 | 実績 | 無作為5% | 無作為中央 | 無作為95% |
|---|---|---|---|---|---|
| A 現行(予測>0.3% かつ 確率>=0.60) | 325 | -8.37% | -22.22% | **-0.56%** | +22.09% |
| B 回帰のみ(予測>0.3%) | 1,141 | -12.42% | （確率を使わないルール） | | |
| C 確率のみ(確率>=0.60) | 388 | **-10.09%** | -67.28% | -42.28% | **-17.54%** |
| D 一致(予測>0 かつ 確率>0.5) | 1,979 | **-31.65%** | -50.94% | -42.36% | **-33.30%** |
| E 現行だが確率>=0.50 | 1,023 | -10.76% | -18.13% | -10.12% | -2.08% |
| F 現行だが確率>=0.55 | 719 | +6.01% | -20.00% | -4.88% | +10.57% |
| G 現行だが確率>=0.65 | 130 | +17.71% | -20.59% | +0.43% | **+23.48%** |

答えは2つに割れ、割れ方が重要です。

**全銘柄から無作為に選ぶのと比べれば、分類器には技術があります。**
C（確率のみ）は 388建玉で -10.09%、同数を全5,500件から無作為に選ぶと中央値 -42.28%、
95%点でも -17.54% です。分類器は明らかにそれを上回っています。D も同様。

**しかし回帰がすでに選んだ銘柄の中では、分類器は何も足していません。**
A（現行）の -8.37% は、同数を無作為に選んだ中央値 -0.56% より **悪い**。
E・F・G もすべて無作為の帯の中に収まり、最良に見えた G の +17.71% は
無作為の95%点 +23.48% に届いていません。

つまり **確率閾値を上げて成績が良くなって見えるのは、閾値ではなく建玉数を
減らしたことの効果です。** 第6-3節の +17.71% も、この対照の中では特別ではありません。

## 9. FX の歴史的効果

**HISTORICAL FX EFFECT = NOT VERIFIED**

理由は2つあり、どちらも単独で十分です。

1. 過去のFXデータに PIT の `available_timestamp` がありません。
   ご指示のとおり、擬似的なタイムスタンプを後から付けることはしていません。
   したがって「08:30時点で実際に利用可能だった」ことを保存された証拠から
   示すことはできません。
2. FX を1営業日ラグで入れた場合の寄与そのものが測れません。符号安定性は
   51.0% / 51.5%（第8-1節）、Ablation は抜いても +0.05pp（つまり悪化しない）、
   Incremental は足しても -0.04pp（つまり改善しない）。両方向とも不合格です。

   つまり **1つ目の理由がなくても結論は変わりません。** PIT記録が仮に
   揃っていたとしても、この期間のUSD/JPYには測定できる寄与がありませんでした。

構造上の保証（1営業日シフト）は成立していますが、それは
「日足の前日値なら08:30に利用可能」という設計上の主張であって、
保存された PIT 記録による検証ではありません。両者を混同しません。

## 12. いま本番に反映すべきこと

検討したが採用しない理由:

| 候補 | なぜ採用しないか |
|---|---|
| 確率閾値を 0.65 に上げる | 全期間を見て選んだ値で、後知恵の上乗せが9.42ポイント。さらに +17.71% は同数を無作為に選んだときの95%点 +23.48% に届いていない |

| 銘柄選択戦略 B か D を入れる | どちらもプラスだが、同数を無作為に選んだ中央値（-0.20% / +0.35%）とほぼ同じで、95%点には遠い |
| compact（38列）に切り替える | 方向的中は +0.55pt だが取引期待値は production より低い。判定順位の上位で負けている |
| 分類器を外す | 回帰のみの方が累積で悪い（-12.42% 対 -8.37%）。ただし現行ルールは同数の無作為選択にも負けているので、「外さない」根拠は弱い |
| 分類器を分位点由来のP(up)に置き換える | Brier・LogLoss・的中の3指標では改善する。だが回帰を本番のまま確率だけ差し替えると、建玉が519→77に減って累積 +4.65%→+3.48%、しかもどちらも無作為の帯の中。確率としては良くなるが、売買成績は良くならない |
| 銅の重みを上げる | Ablation/Incremental の両方向で効き、BH補正も通った唯一の発見。ただし「情報がある」と「その重みにすると儲かる」は別の主張で、後者は測っていない |
| 自銘柄テクニカル7列を外す | 抜いた方が方向的中は +0.47pt 良い。ただし符号検定 p=0.222 で、補正前でも有意ではない |
| バルチック海運指数を外す | 単独で足すと -1.00pt（p=0.023）だが、compactから抜いても ±0.00pt。抜く根拠にならない |
