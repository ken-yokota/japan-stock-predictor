# OOS特徴量調査 2026-08-26

250営業日・5,500予測 × 7アームのWalk-Forward OOSと、本番DBの223予測から。
すべて同一期間・同一walk-forward条件。特徴量選択は各予測日の学習窓内だけで
完結しており、全期間の成績を見て列を選んだ結果はひとつも含まれていない。

---

## 1. Executive Conclusion

**signalは存在するが、順位にだけあり、コストには届いていない。**

日次クロスセクションのRank ICは250営業日で +0.034〜0.047（t = 2.0〜2.6）、
Top5 − Universe は +0.088〜0.117%（t = 2.4〜2.9）。順位付けの能力は統計的に
検出できる。一方で予測の**水準**には情報がない — Calibration slope 0.16〜0.27
（理想1.0）で、誤差指標では「常に0と答える」が全アームに勝つ。

**特徴量は減らすべきだが、効くのは数ではなく中身。** 手選びの compact（38列）
が8指標中7つで最良である一方、自動選択の k=40（40列）は相関と方向的中で明確に
劣る。そして本番の列数を膨らませているのは指標ではなく**変換**である
（本番は指標22・変換10.7本/系列、研究ミラーは指標28・変換2.6本/系列）。

**本番は自分の交差検証が要求するより桁違いに弱い正則化で動いている。**
alpha=100で固定されているが、グリッドを広げるとCVは1,000〜100,000を要求する。

Top5 − Universe +0.098% に対し往復コスト 0.165%。**約6割の地点にいる。**

## 4. Regularization Diagnostics

各アーム132 fit をサンプルし、本番グリッド（0.01〜100）と拡張グリッド
（0.001〜100,000）の両方で選ばれる値を記録した。

| | 72列（現行相当） | 10列 |
|---|---|---|
| 本番グリッドで alpha=100 | **132/132（100%）** | **132/132（100%）** |
| 拡張グリッドで100超を選択 | **88.6%** | **14.4%** |
| 内訳 | 1000×66, 10000×20, 100000×31 | 1000×18, 10000×1 |
| Logistic C ≤ 0.001 | 45% | **0%**（45%はより弱い0.1） |

**本番グリッドでは両者が同じに見える。上限だから区別できないだけだった。**
広げれば、列数がCVの要求する収縮の強さを実際に動かしていることが分かる。

そして本番は alpha=100 で動いているが、CVは 1,000〜100,000 を要求している。
**自分の交差検証が選ぶより桁違いに弱い正則化で走っている。**

## 11. Recommendation

| 対象 | 判定 | 理由 |
|---|---|---|
| 現行の特徴量セット（215〜236列） | **MODIFY** | 重複する4組の変換を削る。指標ではなく変換を減らす |
| Ridge alpha グリッド（上限100） | **MODIFY** | CVが1,000〜100,000を要求している。上限を広げる |
| BUY閾値（予測>0.3% & 確率≥0.60） | **KEEP（当面）** | 予測値と確率が較正されていないため、いま最適化しても意味がない |
| Probability Up による選別 | **DISABLE候補** | Brierが常に50%と答える値以上。無情報より良くない |
| 予測リターンの絶対値の利用 | **DISABLE候補** | slope 0.16〜0.27。順位としてのみ使うべき |
| 自動の単変量特徴量選択 | **REMOVE** | compactに負ける。選択方法として弱い |
| 本番モデルの即時変更 | **しない** | 同一walk-forwardでの比較を経てから |
