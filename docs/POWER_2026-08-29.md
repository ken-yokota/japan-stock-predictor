# この調査は、何を見つけられて何を見つけられなかったか

**「見つからなかった」と「無い」は違います。** この文書は、その差を数字で示します。
コスト0での損益分岐は方向的中 **50%** なので、52〜55%程度の小さな優位性でも
実用上は意味を持ちます。問題は、この調査がその大きさを検出できたのか、です。

---

## 1. 銘柄ごとの検定は、実用的な大きさの優位性をほぼ検出できません

22銘柄・250営業日で、1銘柄だけ本物の優位性があると仮定したときの検出確率
（3,000回のシミュレーション、BH補正後 q<0.05）。

| 真の方向的中率 | raw p<0.05 で検出 | **BH補正後に検出** |
|---|---|---|
| 55% | 34.7% | **7.3%** |
| 58% | 71.4% | 29.9% |
| 60% | 88.4% | 53.3% |
| 62% | 97.0% | 78.3% |
| 65% | 99.9% | 96.0% |
| 70% | 100.0% | 100.0% |

**真に55%の銘柄があっても、この検定が見つける確率は 7.3% です。**

したがって報告書第7節の「BH補正後に有意な銘柄は 0/22」は、
**「優位性のある銘柄は無い」の証拠にはなりません。**
言えるのは「65%級の大きな優位性は無い」までです。

私はこれを「発見ではなかった」の根拠として繰り返し書きました。訂正します。

---

## 2. 全体をプールした検定は、十分な検出力があります

銘柄別ではなく5,874予測をまとめて見る場合（片側、α=0.05）:

| 真の方向的中率 | 有意にできる確率 |
|---|---|
| 51.0% | 33.5% |
| 51.5% | 63.3% |
| **52.0%** | **86.6%** |
| 52.5% | 96.9% |
| 53.0% | 99.6% |

**プールすれば52%は86.6%の確率で検出できます。** つまり
「52%以上の一様な優位性」については、この調査は有効な検定でした。

---

## 3. では未使用期間は何を否定したのか

| | 方向的中 | 95%信頼区間 | 標本 |
|---|---|---|---|
| 検討期間 compact | 52.60% | [51.28%, 53.92%] | 5,500 |
| **未使用期間 compact** | **50.36%** | **[49.08%, 51.64%]** | 5,874 |
| **未使用期間 production** | **51.17%** | **[49.90%, 52.45%]** | 5,874 |
| 本番実績（買いのみ） | 48.33% | [35.69%, 60.98%] | 60 |

読み方は3つです。

1. **検討期間の 52.60% は、未使用期間の区間に入りません**（compact の場合）。
   同じ大きさの優位性が続いていた、とは考えにくい。
2. **しかし未使用期間は「優位性ゼロ」も否定していません。**
   production の区間は [49.90%, 52.45%] で、**52%の優位性を排除できていません。**
   コスト0なら52%は実用的な水準です。
3. **本番実績60件は何も言っていません。** 区間が [35.7%, 61.0%] です。

---

## 4. 正確な結論

| 主張 | 言えるか |
|---|---|
| 検討期間で見えた 52.6% は未使用期間で再現しなかった | **言える** |
| 65%級の大きな優位性を持つ銘柄は無い | **言える** |
| 52%程度の小さな優位性も無い | **言えない**（production の区間は52.45%まで含む） |
| 現行ルールに投資価値がある | **言えない**（対照を上回らない） |
| 現行ルールに投資価値が無い | **言えない**（検出力が足りない） |

**この調査が確立したのは「大きな優位性は無い」までで、
「小さな優位性も無い」ではありません。**

---

## 5. 小さな優位性を判定するには何が必要か

52%を安定して検出するには、プールでおよそ **5,000予測（250営業日）** で足ります。
すでにその規模はあり、未使用期間では 51.17% [49.90%, 52.45%] でした。
区間の幅を半分にするには標本を4倍、つまり **約1,000営業日（4年）** が要ります。

現実的な代替は、**本番で前向きに記録を取り続けること**です。
1日22予測なので、250営業日で5,500予測。
ただしそれは4年ではなく1年で、かつ後から選び直せない記録になります。

いま本番は 2026-08-10 から 14営業日分、311予測です。
**必要な規模の約6%** に達したところです。
