## 分析の目的

設定ファイルは「何を渡したか」しか語りません。**モデルが何に重みを
置いたか**は係数を見ないと分かりません。37指標 x 22銘柄 x 63セッションの
係数を実測し、銘柄ごとに3つを問います。

| 問い | 測り方 |
|---|---|
| 何に依存しているか | 標準化後の係数の絶対値による順位。Ridgeは係数をゼロにしないため、順位で測るしかない |
| それは安定しているか | `max(正の回数, 負の回数) / 全セッション`。1.00=常に同じ向き、0.50=コイン投げ |
| それは当たっているか | 銘柄別の方向的中・MAE・BUY成績 |

特徴量はパイプライン内で標準化されるため、**単位の違う指標同士の
重みが比較可能**です。これが順位に意味を持たせている唯一の根拠です。

**係数は相関の重みであり、因果ではありません。**
