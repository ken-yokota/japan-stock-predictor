## B. リーケージ監査（ゲート）

本番は `shift(1)` ではなく**可視性フィルタ**で防ぐ。`services/dataset.py` が
`available_timestamp` / `timestamp` / `first_observed_at` / `retrieved_at` の
4つすべてが cutoff 以前であることを要求する。

予測日 t の 08:30 時点で t 日の OHLC は存在し得ないため、最新の使用可能行は
t-1 になる。**ラグより強い保証**で、休場や配信遅延で t-1 が間に合わない場合も
正しく除外される。

`feature_inputs`（50,332行）が特徴量1本ごとに使用した価格行IDと3つの
タイムスタンプを保持しており、系譜を完全に追跡できた。

| 検査 | 違反 |
|---|---|
| `src_date >= prediction_date` | 0 |
| `available_timestamp > cutoff` | 0 |
| `first_observed_at > cutoff` | 0 |
| `retrieved_at > cutoff` | 0 |

全 `stock__` 特徴量が t-1 由来。詳細は `reports/leakage_audit.csv`。

**ADR が「自銘柄の価格」と誤表示されていた理由**: 本番の命名は
`{group}__{feature}` で、自銘柄は `stock__` を持つ。以前の集約は `__` 分割に
依存しておらず、単一アンダースコアの指標名（`copper_return_1d`）を扱う実装に
なっていたため、全てが自銘柄に落ちていた。実測では `toyota_adr__` として
独立している。

## E. 判定と理由

事業ドライバーとして正しいことと、**当日の寄り→引けリターンを予測すること**は
別問題だった。政策金利は18か月かけて動き決算に効く。数時間の日中変動には、
その情報は既に価格へ入っているか、そもそも関係しない。

加えて 240特徴量に22本を追加したことで過剰パラメータが悪化した可能性がある。
Ridge が既にグリッド最大の alpha を選ぶ状況で次元を増やせば、縮小が全体へ
強くかかる。

**BUY成績は改善している**（PF 1.77→1.93、Sharpe 1.24→3.10、純損益
+0.342→+0.387、最大DD −0.067→−0.037）。しかし104件対105件の集計値で対応検定を
通していない。主要指標が有意に悪化している以上、これで覆すのは事前基準を
結果を見てから曲げることになる。**Rank IC と BUY成績の乖離は今回で2度目**で、
記録に値する。

## G. 窓を250セッションへ延ばした結果（最重要）

63セッションの窓は**モデルに有利な期間だった**。

| 指標 | 63セッション | **250セッション** |
|---|---|---|
| Rank IC | +0.1119 | **+0.0334** |
| IC p | 0.001 | **0.050** |
| 方向的中 | 0.5570 | **0.5219** |
| BUY勝率 | 0.606 | **0.504** |
| BUY PF | 1.77 | **1.15** |
| BUY Sharpe | 1.24 | **0.38** |
| 最大DD | −0.067 | **−0.176** |

**「断面予測力は統計的に確立（p=0.001）」という以前の分類を撤回する。**
250営業日で測れば p=0.050 の境界線上で、多重比較補正には到底通らない。
コスト20bps差引後の勝率0.504・PF 1.15 は、ほぼ損益分岐点である。

この結果は、今日ここまでの判断を**方向としては強める**。短い有利な窓ですら
悪化した円金利候補が、長い窓で好転する理由はない。指標を足す方向に期待値は
なく、残る筋は削減だけになる。

## H. 一次従属は本番に実在するが、無料データでは測れない

`us_10y_minus_2y_spread` の3本を同時に持ち、設計行列がランク落ちしている。

実在するが本測定では検証できない**。NOT VERIFIED として記録する。
