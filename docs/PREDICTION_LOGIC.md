# 予測ロジック仕様

実装から読み取った内容です。値は `config/*.yaml` と実コードの参照であり、
記憶や設計意図ではありません。

## 1. 何を予測しているか

**目的変数は `intraday_return = 終値 / 始値 − 1`**（当日の寄り引け）。

前日終値からの「窓（ギャップ）」ではありません。この区別が候補指標の大半を
無効にします — 「米株が上げたから日本株も上げる」は真ですが、その情報は
**買値である寄り付きに既に入っている**ためです。

## 2. 締切

**08:30 JST 固定。予測日から決まり、実行開始時刻とは無関係です。**

08:05 に起動しても 08:55 に遅延起動しても、使える情報は同一です。3つの
時刻すべてが締切以前であることを要求します。

| 時刻 | 意味 |
|---|---|
| `available_timestamp` | 市場がその値を知り得る状態にした時刻 |
| `first_observed_at` | 本システムが初めてその値を見た時刻 |
| `retrieved_at` | この行を取得した時刻 |

後ろ2つが「実際に手元にあった」ことの主張です。08:00 に存在したが 08:55 に
取得した値が「08:30 時点で保有していた情報」を騙るのを防ぎます。

## 3. 特徴量

### 自銘柄の価格特徴量（11本、全セットで共通）

`return_1d` `return_2d` `return_3d` `return_5d` `return_20d`
`log_return_1d` `volatility_5d` `volatility_20d` `open_close_return`
`high_low_range` `ma20_deviation`

**全て `shift(1)` で1営業日ラグされます。** `open_close_return` は目的変数
そのものなので、ラグを外すと答えを渡すことになります。

### 海外指標（37系列、`config/indicators.yaml`）

米株指数・先物、VIX、為替、米金利、商品、業種ETF、中国・韓国プロキシ、
海運指数、ADR。特徴量名は `{indicator_id}__{name}` の形式で、どの指標が
寄与したかを名前から判定できます。

1指標あたり複数の特徴量（変化率・差分×窓長）を生成するため、**37指標が
185特徴量程度**になります。学習窓は120営業日なので、**予測子が観測数に
迫ります**。

## 4. 学習

**銘柄ごとに独立。毎朝、全銘柄を学習し直します。** 保存済みモデルは
使いません。

| 項目 | 値 | 出典 |
|---|---|---|
| 学習窓 | **直近120営業日** | `model.yaml: window_jpx_sessions` |
| 最低必要行数 | 120 | `minimum_complete_rows` |
| 欠損許容 | **1行あたり20%超で不採用** | `max_missing_ratio` |
| 交差検証 | TimeSeriesSplit **5分割**、gap=0 | `cross_validation` |
| 乱数種 | 42、`deterministic: true` | `reproducibility` |

### パイプライン（scikit-learn）

```
SimpleImputer(strategy="median", keep_empty_features=True)
  → StandardScaler()
    → Ridge(alpha) または LogisticRegression(C)
```

**補完器とスケーラはパイプライン内**にあるため、交差検証の各フォールドで
**学習部分のみから独立に fit** されます。検証データの統計が学習に漏れません。

### 2つのモデル

| モデル | 出力 | 探索範囲 |
|---|---|---|
| **Ridge** | 予測リターン（連続値） | alpha ∈ {0.01, 0.1, 1.0, 10.0, 100.0} |
| **ロジスティック回帰** | 上昇確率 | C ∈ {0.01, 0.1, 1.0, 10.0} |

分類の目的変数は `intraday_return > 0`。**片方のクラスしか存在しない場合は
分類器を作らず**、学習期間の上昇比率を定数確率として返します。

### 直近重み付け

`recency_half_life_sessions` は**既定 `None`（重み付けなし）**。設定した
場合のみ、指定営業日ごとに重みが半減します。重みは合計が件数に一致するよう
再スケールされます — これをしないと、半減期を短くしただけで実効的な正則化
が強まり、2つの変更が混ざるためです。

### 窓の切り出し順序

**先に直近120営業日を取り、その後に目的変数が非有限な行を捨てます。**
順序が逆だと、欠損した目的変数が窓を過去へ静かに延長します。

## 5. 買いの判定

```
BUY = (予測リターン > 0.30%) かつ (上昇確率 >= 60%)
```

| 項目 | 値 |
|---|---|
| 予測リターン閾値 | **0.003（0.30%）**、`strict_greater_than` |
| 上昇確率閾値 | **0.60**、`greater_than_or_equal` |
| 1銘柄あたり資金 | 1,000,000円 |
| 売買単位 | 100株、`floor(資金 / 始値)` |
| 手数料 | **片側 5 bps** |
| スリッページ | **片側 5 bps** |
| 持ち越し | **なし**（寄りで買い、同日大引けで売る） |

**2条件の同時成立が必要です。** 片方だけでは買いません。往復コストは
20 bps（0.20%）で、閾値0.30%との差が実質的な期待幅です。

## 6. 測定について（2026-08-16 実測）

63セッション・1,386予測・22銘柄で測定した結果です。

| 指標 | 値 |
|---|---|
| **Rank IC（日次断面）** | **+0.1119、p=0.001** |
| 方向的中 | 0.5570 |
| MAE | 1.2564 %ポイント |

**断面の順位付けには統計的に有意な実力があります。** 一方、方向的中で
候補を比較したときの検出下限は約3.1ppで、これを下回る差は「効果がない」
のではなく「測れていない」と読む必要があります。

Rank IC が区別できない4つの特徴量セットで、BUY成績は +0.44 〜 −0.01 に
開きました。**順位指標だけでは採否を決められません。**

## 7. 既知の弱点

| 項目 | 内容 |
|---|---|
| **FX欠損** | usdjpy/eurjpy/audjpy が全22銘柄で必須なのに毎朝欠損。提供元にはデータがあり、本番の取得経路が落としている（調査中） |
| 欠損時も予測を出す | 必須指標が欠けても BUY を出す。抑止ゲートは未実装 |
| 予測子 > 観測数 | 185特徴量に対し120営業日。Ridge の alpha は1,078回中1,078回でグリッド最大を選択（もっと縮めたがっている） |
| 冗長性 | 2年債+10年債+スプレッドは一次従属。現物指数と自らの先物が併存。BDIとCapesize/Panamaxの三重計上 |
| 標本 | 63セッションは取引成績の検定に対して検出力不足 |
