## 5. 何を意味するか

- **検討期間で見えた小さな優位性は、その期間の性質だった可能性が高い。**
  順位IC +0.0426 (t=+2.58) は、22銘柄・250営業日・6アーム・多数の条件を
  試した中から出てきた数字で、多重比較の対象です。第7節でトヨタの 59.2% に
  ついて言ったことが、モデル全体にも当てはまります。
- **第3c節の +17.03% は、期間とグリッドの両方に依存していました。**
  未使用期間の同じグリッドAは -13.43% です。
- **現行の本番ルールは未使用期間で +3.26%（312建玉、t=+0.15）** でした。
  検討期間では -8.37% です。順位が入れ替わっており、どちらも t値が小さく、
  これは「現行ルールが良い」という証拠にもなりません。

### 9-2. しかし PASS の中身を読む必要があります

| | |
|---|---|
| 全22銘柄を毎日買う（コスト込み） | **-70.01%** |

**この期間は寄り引けで買うこと自体が大きく負ける期間でした。**
「無作為を上回った」は「負けが小さかった」という意味で、
黒字なのは3つ中1つ（+4.47%、t=+0.23）だけです。

### 9-3. 断面の順位づけには力がありません

| 指標 | 検討期間 | 未使用 compact | 未使用 production |
|---|---|---|---|
| 方向的中率 | 52.60% | 50.36% | **51.17%** |
| Pearson | +0.0798 | +0.0037 | +0.0245 |
| 順位IC | +0.0426 (t=+2.58) | +0.0112 (t=+0.67) | **+0.0093 (t=+0.55)** |
| Top5超過 | +0.0976% (t=+2.92) | -0.0172% | **-0.0099% (t=-0.26)** |

**Top5超過は未使用期間の両方で負**です。断面全体の順位づけは効いていません。

両立します。閾値ルールが使うのは**予測の上位の裾だけ**で、
順位ICは断面全体を測ります。「裾には情報があるが、全体の並べ替えには
情報がない」というのが、2つの数字が同時に成り立つ読み方です。

これは事後的な確認で、判定基準ではありません。
